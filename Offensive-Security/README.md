# Offensive Security

## Topics Learned

- What ethical hacking is
- White Hat, Black Hat, and Grey Hat hackers
- Penetration Testing
- Vulnerability Assessment
- Responsible Disclosure

## Skills Learned

- Understanding the attacker's mindset
- Identifying system weaknesses
- Following legal and ethical hacking practices
- Basic penetration testing concepts

## My Notes

Offensive Security focuses on finding and reporting security weaknesses before attackers can exploit them. Ethical hackers perform authorized testing to improve an organization's security while following strict legal and ethical guidelines.
